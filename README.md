# Сайт юридической фирмы

Сайт разработан по заказу юридической фирмы "Твёрдый знак". Работа выполнена в рамках проектной деятельности в колледже IT-hub.

## Инструкция по запуску

1. Скачать проект с помощью команды ```git clone https://github.com/SashaORH/-.git```

2. Создать виртуальное окружение с помощью команды ```python -m venv .venv```

3. Активировать виртуальное окружение с помощью запуска файла ```Activate``` командой ```./.venv/Scripts/Activate```

4. Установить зависимости командой ```pip install -r requirements.txt```

5. Запустить веб-приложение с помощью команды ```python manage.py runserver```
